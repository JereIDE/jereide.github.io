Versions Released

Fast.

JereIDE is written in pure Rust, built on egui and eframe. It is an immediate-mode framework, which means it renders on your screen EVERY FRAME!

Rust has its speed advantages, but it's still a challenge to keep JereIDE fast while adding syntax highlighting. If you'd like to help, file a PR!

Simple.

With a command palette, easy-to-learn keyboard shortcuts, and customizable settings(coming in the future), JereIDE is super easy to use. Syntax highlighting is built-in!

Open Source.

JereIDE is open source!
